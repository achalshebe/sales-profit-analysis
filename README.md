# Sales and Profit Analysis using Python and Power BI

## Project Overview

This project focuses on analyzing sales and profit data using Python and Power BI. The objective was to clean and process raw data, identify useful business insights, and create interactive visualizations for better understanding of sales performance and profitability.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI
- Jupyter Notebook

## Data Processing

The dataset was cleaned and prepared using Python. The main preprocessing steps included:

- Checking the dataset structure
- Handling missing or inconsistent values
- Checking and removing duplicate records
- Verifying data types
- Filtering unnecessary data
- Sorting and preparing data for analysis

## Python Analysis

Python was used for exploratory data analysis and visualization.

The analysis included:

- Product-wise sales analysis
- Region-wise sales analysis
- Sales trend analysis
- Profit distribution analysis
- Sales vs. profit relationship

## Power BI Dashboard

An interactive Power BI dashboard was created to visualize:

- Total Sales
- Total Profit
- Total Quantity Sold
- Total Orders
- Product-wise Sales across Regions
- Region-wise Sales Distribution
- Sales Performance vs Target
- Sales Trend
- Sales vs Profit Relationship
- Profit Distribution

Interactive filters were also added for Product and Region.

## Key Insights

- Sales performance varies across different products and regions.
- Different regions contribute differently to overall sales.
- Sales fluctuate across different orders.
- The dataset contains both positive and negative profit values.
- Product and regional analysis helps identify sales and profitability patterns.

## Project Files

- Sales_Analysis.ipynb – Python data cleaning, analysis and visualization
- Sales_Profit_Analysis.pbix – Power BI interactive dashboard

## Conclusion

This project demonstrates how Python can be used for data cleaning and analysis and Power BI can be used to create interactive business dashboards and communicate meaningful insights from data.
